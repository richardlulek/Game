# Lanseringslista: viktade funktioner att pusha

Vikt 1–10 = hur hårt funktionen ska drivas i lanseringskommunikationen.
Vikten väger tre saker: **differentiering** (finns det i andra tycoons?),
**begriplighet** (kan den förklaras på fem sekunder?) och **demobarhet**
(syns den i en trailer/skärmdump?). Kanal anger var funktionen hör hemma:
T = trailer, S = Steam-sidans säljtext/bullets, P = press/creators,
B = butiksbilder/GIF:ar.

## Nivå C — nämns men drivs inte (patch notes-nivå i lanseringen)

Deterministisk seed/reproducerbara partier · 3 sparplatser + export/import ·
svårighetsgrader och Friläge · policy/förvaltarautomation · detaljplane-
auktioner · byggnadslivscykel/obsolescens · politik & kampanjstöd ·
notabla hyresgäster · aktiehandel med blankning och limit-ordrar.

## Tumregler för materialet

1. **Trailerns dramaturgi = spelets tre pelare i ordning:** staden som
   andas (etablering) → rivalerna som slår tillbaka (konflikt) → raiden
   mot ditt eget bolag (klimax). Sluta på "Bygg imperiet. Försvara det."
2. **Varje skärmdump ska visa ett BESLUT**, inte en meny: budpliktens
   tvångsval, renovräkningsdialogen, deal pipeline med "distressed —
   easy prey", nemesis-rubriken "THE CITY TURNS".
3. **Pressvinkeln är nivå A:s etiska val** (renovräkning/gentrifiering) –
   det är storyn journalister kan skriva om; M&A-motorn är storyn
   creators kan spela.
4. Nivå C hålls UTANFÖR säljtexten – djup som upptäcks slår djup som
   utlovas.
